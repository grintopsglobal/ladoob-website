## Empat produk

Judul panel kini tanpa nama produk (nama sudah ada di tab), fitur ditulis dalam huruf kalimat biasa, dan kalimat sorotan dibuat lebih konkret.

| Produk | Judul panel sesudah | Sorotan sesudah |
|---|---|---|
| Core | Pusat kendali untuk owner dan tim operasional | Satu perubahan, semua aplikasi ikut terbarui |
| Compass | Pendamping perjalanan untuk wisatawan | PDF tidak lagi tercecer di grup chat |
| Masar | Pendamping ibadah dan perjalanan jamaah di Tanah Suci | Pertanyaan berulang ke muthawwif berkurang |
| Agent | Alat jual untuk agen, reseller, dan affiliator | Mitra mengecek sendiri, admin tidak dikejar pertanyaan |

"Ratusan pertanyaan berulang" di sorotan Masar menjadi "pertanyaan yang sama berkali-kali", karena angkanya tidak bersumber.
